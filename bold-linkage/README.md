# BOLD Linkage

This folder contains documentation and resources for the BOLD Linkage feature, which enables [DiSSCo](https://www.dissco.eu/) (Distributed System of Scientific Collections) to query the [BOLD](https://www.boldsystems.org/) (Barcode of Life Data Systems) API to enrich digital specimens.

  - Examples and use cases

## Quick Overview

The BOLD Linkage feature provides a bridge between TreeBASE's phylogenetic data and BOLD's DNA barcode database. Key capabilities include:

- **Molecular Verification**: Confirm species identifications using DNA barcodes
- **Data Enrichment**: Augment specimen records with sequence data and collection details
- **Cross-Reference Discovery**: Find related specimens by matching barcode sequences
- **Provenance Tracking**: Link published phylogenetic trees to voucher specimens
